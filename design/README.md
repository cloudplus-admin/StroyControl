# UI/UX-дизайн StroyControl

Визуальный дизайн ключевых экранов веб-интерфейса. Живые HTML/CSS-макеты — не
конечный продакшн-код, а дизайн-каркас (кликабельная статика) на единой
дизайн-системе для передачи фронтенд-разработке и обсуждения с заказчиком.

## Дизайн-система

`design-system.css` — цвета, типографика, отступы, компоненты (карточки,
бейджи статусов, кнопки, прогресс-бары, вкладки), фирменные иконки
(`icons.svg` — inline SVG-спрайт, без внешних шрифтов/CDN) и лёгкие
анимации (fade-in карточек, заполнение прогресс-баров, hover-эффекты,
sticky-топбар с блюром). Палитра статусов: 🟢 в графике/готово, 🟠 риск
срыва, 🔴 просрочено/срыв, ⚪ не начато — используется единообразно во всех
модулях (графики, задачи, дефект-лист).

## Как открыть макеты локально

```bash
cd design && python3 -m http.server 8000
# затем открыть http://localhost:8000/01-objects-dashboard.html
```

## Демо-приложение (APK)

`../mobile/stroycontrol-demo/` — эти же экраны, упакованные через Capacitor
в нативную Android-оболочку (WebView), для просмотра дизайна прямо на
телефоне. Это визуальное демо, не production-приложение (нет связи с
backend/API) — см. `../mobile/stroycontrol-demo/README.md`.

## Не входит в этот каркас

- Мобильный UI как отдельная нативная реализация (раздел 13 ТЗ) — макеты
  адаптированы под десктоп, APK-демо просто оборачивает их в WebView
- Экраны Этапа 2/3 (финансы, снабжение, видеонаблюдение, AI-функции)
- Реальная интерактивность (формы с валидацией, модальные окна, drag&drop)
- Финальная предметная проработка в Figma с передачей спецификаций (redlines, компонентная библиотека)
