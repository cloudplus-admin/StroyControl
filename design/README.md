# UI/UX-дизайн StroyControl

Визуальный дизайн ключевых экранов веб-интерфейса. Живые HTML/CSS-макеты — не
конечный продакшн-код, а дизайн-каркас (кликабельная статика) на единой
дизайн-системе для передачи фронтенд-разработке и обсуждения с заказчиком.

## Дизайн-система

`design-system.css` — цвета, типографика, отступы, компоненты (карточки,
бейджи статусов, кнопки, прогресс-бары, вкладки). Палитра статусов:
🟢 в графике/готово, 🟠 риск срыва, 🔴 просрочено/срыв, ⚪ не начато —
используется единообразно во всех модулях (графики, задачи, дефект-лист).

## Как открыть макеты локально

```bash
cd design && python3 -m http.server 8000
# затем открыть http://localhost:8000/mockups/01-objects-dashboard.html
```

## Не входит в этот каркас

- Мобильный UI (раздел 13 ТЗ) — отдельная итерация под iOS/Android
- Экраны Этапа 2/3 (финансы, снабжение, видеонаблюдение, AI-функции)
- Интерактивные состояния (hover, модальные окна, формы валидации)
- Финальная предметная проработка в Figma с передачей спецификаций (redlines, иконостиль, компонентная библиотека)
