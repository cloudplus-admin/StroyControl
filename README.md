# StroyControl

Платформа цифрового управления строительством — единая система контроля объектов,
задач, документов и финансов для CloudPlus.

Основано на ТЗ «Платформа цифрового управления строительством "StroyControl"»,
г. Ташкент, версия 1.0 (15.06.2026).

## Структура репозитория

```
stroycontrol/
├── backend/     — API-сервер (Node.js + TypeScript + PostgreSQL)
├── web/         — веб-интерфейс (React + TypeScript)
├── mobile/      — мобильное приложение (iOS/Android, кроссплатформенное)
└── docs/        — архитектура, схема БД, RBAC, окружения
```

## Документация

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — архитектура и стек технологий
- [docs/DATABASE_SCHEMA.sql](docs/DATABASE_SCHEMA.sql) — схема БД (DDL)
- [docs/RBAC.md](docs/RBAC.md) — матрица прав доступа
- [docs/ENVIRONMENTS.md](docs/ENVIRONMENTS.md) — окружения, CI/CD, бэкапы

## Быстрый старт (backend)

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

## Быстрый старт (web)

```bash
cd web
npm install
npm run dev
```

## Локализация

Интерфейс поддерживает русский и узбекский языки (см. `web/src/i18n`).

## Статус

Этап 0 (подготовка): архитектура, схема БД, RBAC-модель, CI/CD-конфигурация и
скелеты backend/web — выполнены в этом репозитории.

Не выполнено в рамках Этапа 0 (требует решений/доступов заказчика, не может быть
сделано автоматически):
- Подписание ТЗ заказчиком (раздел 20 ТЗ)
- Выбор и оплата реального облачного провайдера, домена, S3-хранилища
- UI/UX-дизайн в Figma (сделан только структурный каркас интерфейса)
